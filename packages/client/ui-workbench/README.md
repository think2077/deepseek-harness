# LTC workbench

Browser plugin contributing My workbench above My reviews. The main panel presents ten illustrative business and operations nodes with stage filters. Solutions and Pre-visit plan open local mock previews; all other tools are disabled. No tasks execute and no data is persisted. Labels support English and Chinese. There is no plugin configuration.

## Model Experience

This plugin adds no model input, tools, or session events. It publishes no runtime invariant because it owns no independently observable runtime relationship.
