# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

## 概述

我的工作台展示商务与运营两个阶段的十个 LTC 场景节点。每个节点可以展示多个助手。「接待助手」通过商务专家启动新的项目会话，「行前方案」通过解决方案专家启动新的项目会话。未选项目时，用户先选择工作空间。「项目筹备助手」仍为预览。

## 使用本包

浏览器插件在「我的审核」上方提供「我的工作台」。主面板展示商务与运营两个阶段的十个示例流程节点，支持阶段筛选。每个已开放助手都在当前会话所属项目的工作空间中创建全新会话；未选项目时，先让用户选择已有工作空间。会话在打开前应用该助手的 preset，不自动提交提示词。Host 必须提供对应 preset；创建或选择失败会在工作台显示错误。Preset 选择失败时可能留下未打开的空会话。用户发起其他导航后，尚未完成的启动不会再次打开会话。

「项目筹备助手」打开本地预览，其他工具禁用。页面支持中英文，无插件配置，需要会话、工作空间、预设及工作空间导航的 Client 服务。

## 模型体验

### 预设选择

#### 模型看到什么

助手选择的 preset 拥有模型可见的组合。打开会话不会提交提示词。

#### Token 影响

本插件不增加提示词文本或工具 schema，后续请求使用所选预设对应的 token 开销。

#### KV 缓存影响

每个新会话从所选预设建立提示词前缀。已有会话保留其组合与缓存。

## 已知限制与后续工作

「接待助手」与「行前方案」会启动真实会话。工作空间必须已存在，Host 必须分别提供 `business-expert` 与 `solution-expert`。其他场景仍为预览或禁用。
