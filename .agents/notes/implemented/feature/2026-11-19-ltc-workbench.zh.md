# Agent Note: LTC 工作台会话

Status: implemented

[English](2026-11-19-ltc-workbench.md) | 中文

## 问题

项目场景需要统一入口，使用指定工作空间和预设启动会话，同时保留已有会话。

## 决策

工作台是独立浏览器插件，入口位于我的审核上方。十个示例节点覆盖商务拓展与运营阶段。「行前方案」在当前会话所属工作空间中创建新会话；没有当前项目时，用户先选择已有工作空间。每次启动先选择固定的 `solution-expert` 预设，再打开会话。不复用已有空会话，因此启动场景不会改变其他会话的预设。「项目筹备助手」打开本地预览，其他能力使用禁用按钮。支持状态不代表项目完成情况。阶段筛选仅影响展示，所有产品文案由中英文类型化词典维护。

创建与预设选择复用现有 Host API。预设 ID 为此部署固定值，不暴露插件配置。预设缺失或无效时明确显示失败；选择失败可能留下未打开的空会话。打开会话不提交提示词。后续导航会覆盖尚未完成的启动，执行中的保护会阻止重复点击创建多个会话。

## 考虑的替代方案

复用工作空间中的空会话可能改变另一个场景已准备好的会话。自动选择最近工作空间可能将项目文件放进无关目录。因此，每次创建新会话，且未选项目时明确选择工作空间。

## 影响

组件测试覆盖工作空间选择与取消、当前项目路由、空工作空间列表、失败重试、阶段筛选及预览行为。Loader 组合测试固定侧栏输出，验证全新会话创建、跳转前的预设选择、选择失败、后续导航覆盖，以及注册清理。本次不修改持久化类型。
