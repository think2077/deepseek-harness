# Agent Note: 只读管理驾驶舱

Status: implemented

[English](2026-11-25-management-cockpit.md) | 中文

## Problem

运营人员需要统一查看项目进展和数字员工活动，但当前需求不需要新增业务实体、统计存储、审批引擎或流程后端。将该概览放进项目管理插件也会耦合两个应当独立选择的产品区域。

## Decision

Web bundle 将 `@deepseek-ai/dsh-client-ui-management-cockpit` 作为独立客户端插件挂载。该插件自行订阅项目元数据，并在渲染时将项目数据与标准工作区、会话和后台任务快照组合。现有九个项目阶段代码仍是唯一阶段定义。

流程弹窗使用组件本地状态。关闭、取消或保存都会关闭弹窗并丢弃草稿；没有 Remote 方法、会话事件、存储记录或浏览器持久化表示该草稿。

## Alternatives considered

**将页面加入 `ui-projects`。** 这样可以用更少代码复用订阅，但会让展示驾驶舱成为项目元数据管理的一部分，并阻止两者独立组合。

**增加统计和流程服务。** 这样可以提供持久化统计与配置，但会增加超出当前纯展示范围的产品行为。

## Consequences

该插件可以在不修改项目管理的情况下独立挂载、移除和演进。页面数值来自现有客户端投影，并继承其可见范围和更新时间。“待审核工作成果”保持为零，风险文字仅作描述且不调用模型，流程编辑在关闭后不会保留。
