# Agent Note: 基于预设的数字员工目录

Status: implemented

[English](2026-11-25-digital-employee-directory.md) | 中文

## 问题

用户需要在开始项目对话之前发现助手并查看其能力。设置中的预设选择没有提供独立的浏览入口。

## 决定

独立的 `ui-digital-employees` 浏览器插件在「我的审核」正上方注册「数字员工」。预设列表仍是身份来源。卡片展示元信息与可用状态；详情读取已有 Host 插件清单，不挂载智能体，也不返回配置值。能力组成展示启用状态，不承诺固定的工具清单。

工作空间导航包拥有 `createPresetSessionLauncher`，由目录与工作台共用。启动会创建全新的工作空间对话，在打开前选择指定预设。没有当前项目时，用户选择已有工作空间。后续导航会取代未完成的启动，插件卸载会撤销其导航权限。[工作台决定](2026-11-19-ltc-workbench.zh.md)继续拥有场景入口；目录提供完整的已发现预设列表。

## 考虑过的替代方案

**独立员工表**会重复预设身份，目前没有独立归属或状态的需求。当多名员工需要共享预设时，可以引入稳定的员工身份。

**挂载所有预设以查看工具**会在浏览时激活插件。已有清单能够描述配置条目，无需创建会话或激活尚未挂载的组合。

## 影响

本功能不增加持久化类型或 Host API。现有预设管理保持独立。能力组成不暴露人设文本、知识内容或逐会话实际工具清单。选择失败可能留下未打开的空会话。Loader 组合测试覆盖本地化导航、启动顺序、失败、导航取代与卸载；组件测试覆盖浏览、搜索、详情、工作空间选择与空状态和错误状态。
